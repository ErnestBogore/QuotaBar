# Changelog

## 0.4.0

- Added a first-run welcome screen for Applications, alerts, and the optional Mac prompt pause.
- Added macOS notification banners with sound at 75%, 50%, 30%, and 0% remaining, plus a test button.
- Added automatic update checks, one-click install and restart, and a discreet What's New panel.
- Clarified the menu-bar status to show exactly what is left.
- Added a stable direct-download link for the website.
- Replaced the ZIP-first install with the familiar drag-to-Applications disk image.

## 0.3.1

- Added the signed in-app updater foundation.
- Improved the menu-bar popover behavior and five-hour meter presentation.
